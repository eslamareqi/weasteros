# Weasteros — موقع تحويل النص إلى صوت

موقع عربي لتحويل النص الإنجليزي إلى صوت بلهجة بريطانية، مع أصوات Gemini TTS وخيار نطق بريطاني مدمج في المتصفح.

## التشغيل العام الآمن

- الواجهة ثابتة ويمكن نشرها على GitHub Pages من إعدادات المستودع باختيار فرع `main` ومجلد `/`.
- التحويل بجودة Gemini يمر عبر الخادم الوسيط في `server.js` حتى لا يظهر مفتاح API في كود المتصفح أو المستودع العام.
- يحفظ الخادم المفتاح في المتغير السري `GEMINI_API_KEY`، مع حد للطلبات والتحقق من المدخلات.
- عند تعذر خدمة الخادم، يعمل النطق البريطاني المدمج في المتصفح تلقائيًا.

## الملفات

- `index.html`: الواجهة الرئيسية.
- `style.css`: التنسيقات.
- `script.js`: منطق الواجهة واستدعاء الخادم الوسيط.
- `server.js`: نقطة API الآمنة وتقديم الملفات الثابتة.
- `standalone-all-in-one.html`: نسخة مستقلة كاملة.
- `Dockerfile`: إعداد تشغيل الخادم في الإنتاج.
- `Dockerfile`: إعداد تشغيل الخادم الوسيط في الإنتاج.
