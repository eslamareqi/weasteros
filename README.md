# موقع تحويل النص إلى صوت (British Accent TTS)
Developed by **Eslam** ✨🚀

## محتويات الملف المضغوط:
1. `index.html` : الصفحة الرئيسية للموقع (مع نسخة مدمجة بالكامل أيضاً في `standalone-index.html`).
2. `style.css` : ملف التنسيقات والألوان الفاتحة المتدرجة.
3. `script.js` : كود تشغيل وتحويل النص إلى صوت باللهجة البريطانية وتحميله بصيغة `WAV`.

## طريقة إضافة مفتاح API والنشر:
- **الطريقة الأولى (من داخل الكود قبل الرفع):**
  افتح ملف `script.js` وضع مفتاحك في السطر الأول داخل المتغير:
  `const DEFAULT_API_KEY = "AIzaSy...";`
- **الطريقة الثانية (مباشرة من المتصفح بعد النشر):**
  اضغط على **أيقونة الموجات الصوتية الزرقاء** الموجودة بجانب العنوان في أعلى الموقع، وستظهر لك نافذة صغيرة لإدخال المفتاح وحفظه في المتصفح.
- **في حال عدم وضع مفتاح:**
  سيعمل الموقع تلقائياً باستخدام النطق البريطاني المدمج في المتصفح (`en-GB`) كبديل مجاني فوري.
